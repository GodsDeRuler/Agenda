# Horeca-agenda HC Tilburg

Webversie van de horeca-agenda. De gegevens staan in Supabase (project "HC Tilburg horeca");
inloggen is nodig, accounts maakt de beheerder aan via de knop Account rechtsonder.

`index.html` wordt gemaakt met `bouw-supabase-versie.py` uit de actuele agenda; niet met de hand aanpassen.
